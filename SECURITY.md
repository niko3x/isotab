# Reporting security vulnerabilities

Use GitHub's **Security > Report a vulnerability** feature to report a suspected
vulnerability privately. Include reproduction steps, affected browser and
Linux versions, and the potential impact. Do not attach real browsing data or
credentials. Avoid public issues for vulnerabilities before they are resolved.

IsoTab is under active development. Security fixes target the latest source on
the main branch; there are no supported versioned releases yet.

See [SECURITY-AUDIT.md](SECURITY-AUDIT.md) for the documented review scope and
remaining limitations. Browser profile separation is not an operating-system
sandbox or a separate network identity.
